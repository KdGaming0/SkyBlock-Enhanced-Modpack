# 🛠 Update 5.2.0

Full changelog between 5.1.6 and 5.2.0.

Note: Voxy has been removed, and I have reverted to Bobby. After receiving bug reports about weird chunk rendering in 5.2.0-beta.1, I found that Voxy performs poorly on lower-end hardware and does not work on macOS. So, sadly, I have been forced to revert the change.

I still believe Voxy is the better mod, but only if you have the hardware to run it. If you want to use Voxy, you can do !add-mod in any chat in the discord to learn how to add it back.

### 🛠 Troubleshooting & Tips
- Getting random crashes and you are using shaders? Disable Iris. The mod has been unstable lately, as it is on life support while a new replacement is being developed.
- The first launch after updating may take slightly longer than usual.
- If Modrinth does not show the update, refresh the instance page or just wait abit.
