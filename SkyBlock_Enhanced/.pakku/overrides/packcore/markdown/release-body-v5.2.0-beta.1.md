# 🛠 Update 5.2.0-beta.1

New update with new changes, wow! This time around the big change is the addition of Voxy and the removal of Bobby. For the past few months there have been quite a few crashes related to a corrupt Bobby cache and just general issues with cache chunks showing up in the wrong islands. With the change to Voxy this should now be fixed, and you are also able to see even further! (You will now be able to see all islands from the hub after you load in the chunks one time first.) The downside may be a small hit to your FPS, but it should be minor, so I hope you're able to run the modpack with this mod. If you run into issues, please let me know.

I also recommend running `/packcore performance-profile maxfps|balanced|quality|shaders_balanced|shaders_quality` to apply new optimized video configs for use with Voxy.

## ➕ Added
### Mods
- **Custom Scoreboard** - Added custom scoreboard as Skyhanni version is deprecated
- **Fast Server Pings** - Repalces Fast IP Ping, is even faster
- **Voxy Hypixel Addon** - Let's Voxy-cache each skyblock island separately so they don't overlap, with the option to cache chunks that share a coordinate space together so you can see all of them.
- **Voxy** - Renders chunks outside your render distance in lower quality LODs to let you see far without killing your FPS (if you are on mobile you want to add Poxy to or disable Voxy.)
## ➖ Removed
### Mods

- **Fast IP Ping**
